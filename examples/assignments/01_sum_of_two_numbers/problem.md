# Problem 01: Sum of Two Integers

## Description
Write a program that reads two space-separated integers, `A` and `B`, from standard input (`stdin`), and writes their sum to standard output (`stdout`), followed by a newline character.

## Constraints
- `-1,000,000 <= A, B <= 1,000,000`
- Time limit: 2000 ms
- Memory limit: 64 MB

## Sample Input
```text
15 25
```

## Sample Output
```text
40
```
